# Soutenir Sapphire Star Codex

Un soutien volontaire aide le développeur indépendant à maintenir l’application, améliorer les traductions et mettre à jour les données. L’application reste gratuite, sans publicité ; les contributions ne débloquent aucun contenu, fonction ou avantage.

Scannez le code correspondant avec Alipay ou WeChat Pay. Sur le même téléphone, enregistrez l’image puis sélectionnez-la dans la fonction de lecture de codes de l’application de paiement. Vérifiez le destinataire et le montant avant de confirmer.
