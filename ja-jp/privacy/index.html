プライバシーポリシー ​

施行日・最終更新日：2026年10月31日

このポリシーは、Sapphire Star Codex（日本語名「青い星のハンターノート」）の iOS、Android、HarmonyOS アプリと、このウェブサイトに適用されます。開発者は eurekaffeine（刘耀晨） です。プライバシーに関するお問い合わせは eurekaffeine.work@gmail.com へお送りください。

アプリは開発中で、機能はプラットフォームによって異なります。以下は現在のアプリとウェブサイトにおける情報の取り扱いです。アプリの利用にアカウント登録は必要ありません。

端末に保存するデータ ​

設定を記憶し、各機能を提供するため、アプリは端末内にデータを保存します。利用するプラットフォームと機能に応じて、次の内容が含まれます。

  • 選択した作品、言語、表示などの設定。
  • 検索履歴と、画面の状態を復元するための情報。
  • お気に入りのモンスター、装備などの図鑑項目。
  • 保存した装備セット、自分で付けた名前、装飾品の数、護石や防具の所持情報。

これらは閲覧、検索、お気に入り、装備の検討に使います。アプリが開発者へアップロードすることはなく、開発者が運営するアカウントやクラウド同期サービスもありません。

権限と自動収集 ​

現在のアプリには、広告、追跡、利用状況の分析、クラッシュ情報の自動送信を行う SDK を組み込んでいません。現在の機能は連絡先、位置情報、カメラ、マイク、写真ライブラリへのアクセスを求めず、広告識別子も収集しません。

OS やアプリストアは、それぞれの設定とポリシーに基づき、インストールや診断に関する情報を別途処理する場合があります。プラットフォームから診断情報が提供された場合は、アプリの問題調査に使用します。

お問い合わせで受け取る情報 ​

メールでお問い合わせいただくと、送信元のメールアドレス、本文、ご自身で添付したファイルを受け取ります。これらは返信、問題の調査、プライバシーに関するご依頼への対応に使用します。必要な情報だけをお送りください。お問い合わせの内容を広告やメール配信リストに利用することはありません。

ウェブサイト、バックアップ、外部サービス ​

ウェブサイト。 このサイトは GitHub Pages で配信しています。アクセス解析、広告用 Cookie、追跡ピクセルは追加していません。サイト内検索はブラウザ内で動作し、表示や検索の設定がブラウザに保存される場合があります。アクセス時には GitHub が IP アドレスやブラウザ情報などの技術的なリクエスト情報を受け取ります。詳しくは GitHub のプライバシー声明をご確認ください。

端末のバックアップ。 OS の設定によって、アプリのデータが端末やクラウドのバックアップに含まれる場合があります。バックアップは各プラットフォーム事業者が管理しており、私たちが代わりに読み取ったり削除したりすることはできません。

メールと外部リンク。 お問い合わせ窓口には Gmail を使用しています。Google は Google のプライバシーポリシーに基づいて、メールサービスの提供に必要な情報を処理します。外部サイトやアプリストアを開くと、それぞれのポリシーが適用されます。ホスティング、メール、バックアップの事業者が、お住まいの国以外で情報を処理する場合もあります。

情報の共有、保存期間、削除 ​

個人情報を販売・貸与したり、広告のために共有したりすることはありません。お送りいただいたメールは、上記のメール事業者を通じて処理されます。法律で求められる場合や、ご本人から明確な依頼がある場合には、実際に保有する情報を提供することがあります。

  • アプリ内のデータ： アプリの削除機能や端末の設定から消去できます。端末内のデータを消去するには、アプリとデータを両方削除する操作を選んでください。データを残してアプリだけを取り除く操作やアーカイブでは、データが保持される場合があります。バックアップは別に管理する必要があり、再インストール時にデータが復元される場合もあります。
  • ウェブサイトの設定： このサイトの保存データをご自身で消去するか、ブラウザが消去するまで保持されます。
  • メールや共有された診断情報： お問い合わせへの対応、追加調査、法的義務に必要な期間のみ保持します。法律上の保存義務がある場合を除き、お送りいただいた情報の削除を依頼できます。
  • 事業者が保有するデータ： バックアップやアクセスログなどは、その事業者の保存ルールと管理機能に従います。

お送りいただいた情報の確認、訂正、削除は、下記の窓口へご連絡ください。端末内にしか存在しない記録を、私たちが遠隔で読み取ったり削除したりすることはできません。

安全対策 ​

端末内のデータは、OS が提供するアプリ用ストレージの保護を利用します。このサイトは HTTPS で配信します。お問い合わせメールへのアクセスはサポートとプライバシー対応のために行い、メール事業者の安全対策を利用します。

お子様のプライバシー ​

アプリの利用に個人プロフィールや生年月日の入力は必要なく、お子様から意図的に個人情報を求めることもありません。お子様が個人情報を送信したと思われる場合は、保護者の方からご連絡ください。削除について対応します。

ポリシーの変更 ​

取り扱いが変わる場合は、このページと日付を更新します。重要な変更はウェブサイトやアプリの更新情報でお知らせします。新しい機能で権限や同意が必要になった場合は、その操作時に別途確認します。このポリシーだけで同意があったとは扱いません。
