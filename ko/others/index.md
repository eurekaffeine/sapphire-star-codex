# Sapphire Star Codex 소개

## 프로젝트 소개

Sapphire Star Codex는 몬스터 헌터 자료 조회와 방어구 세트 검색을 제공하는 앱입니다. [Pocket Gallery](https://eurekaffeine.github.io/pocket-gallery/) 개발자가 독립적으로 개발하고 관리합니다. 광고와 유료 기능 없이 무료로 제공됩니다.

Android 버전은 [Google Play](https://play.google.com/store/apps/details?id=com.eurekaffeine.mhd), HarmonyOS 버전은 [AppGallery](https://appgallery.huawei.com/app/detail?id=com.eurekaffeine.monsterhunterdex&channelId=SHARE&source=appshare)에서 제공됩니다. iOS 버전은 출시 준비 중입니다. [다운로드](../#download)에서 링크를 확인하세요. 이용 가능 여부는 지역과 기기에 따라 다릅니다.

## 의견 및 협력

문제를 알릴 때는 게임, 항목, 언어, 재현 과정과 확인 가능한 출처를 적어 주세요. 스크린샷의 개인정보는 가려 주세요. 연락처: [eurekaffeine.work@gmail.com](mailto:eurekaffeine.work@gmail.com). 앱 공유, 자료 수정 제안, [자발적 후원](../support/)도 도움이 됩니다.

## 자료 출처와 권리

자료는 [MHDB Wilds](https://docs.wilds.mhdb.io/), [MHW DB](https://mhw-db.com/), 게임 파일 등에서 가져와 커뮤니티 자료와 대조합니다. 누락이나 오류가 있을 수 있습니다. Monster Hunter의 이름, 이미지와 게임 데이터는 CAPCOM의 소유이며 권리자의 삭제 요청에 협조합니다. Pocket Gallery에서 가져온 코드의 MIT 라이선스는 게임 이미지나 데이터를 포함하지 않습니다.
