## الأذونات والجمع التلقائي

لا يحتوي التطبيق على حزم برمجية للإعلانات أو التتبع أو إحصاءات الاستخدام أو إرسال تقارير الأعطال تلقائيًا. لا تتطلب الميزات الحالية الوصول إلى جهات الاتصال أو الموقع أو الكاميرا أو الميكروفون أو الصور، ولا تجمع معرّفات الإعلانات. قد تعالج أنظمة التشغيل والمتاجر بيانات التثبيت أو التشخيص وفق سياساتها. يستخدم المطوّر بيانات التشخيص التي توفرها المنصات لحل المشكلات فقط.

## التواصل والخدمات الخارجية

عند إرسال بريد طوعي، يتلقى المطوّر عنوانك والرسالة والمرفقات للرد والتحقيق في المشكلات ومعالجة طلبات الخصوصية، وليس للتسويق. أرسل المعلومات الضرورية فقط. يعالج Gmail البريد وفق [سياسة Google](https://policies.google.com/privacy).

يستضيف GitHub Pages هذا الموقع وقد يتلقى عنوان IP ومعلومات تقنية عن المتصفح؛ راجع [بيان GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). لا تُضاف تحليلات للزيارات أو ملفات تعريف ارتباط إعلانية أو وحدات بكسل للتتبع. يعمل البحث داخل المتصفح، الذي قد يحفظ التفضيلات. تطبق الخدمات الخارجية سياساتها الخاصة وقد تعالج المعلومات خارج بلدك.

## المساهمات والنسخ الاحتياطية

تعالج Alipay أو WeChat Pay المساهمات وفق شروطها. يعرض الموقع رموزًا ثابتة فقط، دون حزمة دفع برمجية أو تلقي بيانات اعتماد الدفع. قد يرى المطوّر المعلومات التي تعرضها المنصة للمستلم، مثل المبلغ والوقت والاسم الظاهر والملاحظة، للتحقق من المساهمات وحل المشكلات. تخضع مدة الاحتفاظ لقواعد المنصة والالتزامات المعمول بها. بحسب إعدادات النظام، قد تدخل بيانات التطبيق في نسخ احتياطية للجهاز أو السحابة؛ ولا يستطيع المطوّر قراءة تلك النسخ أو حذفها.

لا يبيع المطوّر المعلومات الشخصية أو يؤجرها أو يشاركها للإعلانات. يعالج مزوّد الخدمة المذكور البريد. يمكن تقديم المعلومات المحتفَظ بها فعليًا عند وجود التزام قانوني أو طلب صريح من المستخدم.

يمكن حذف البيانات المحلية عبر التطبيق أو إعدادات النظام. إزالة التطبيق مع الاحتفاظ ببياناته لا تمحوها؛ ويجب إدارة النسخ الاحتياطية بصورة منفصلة لأنها قد تستعيد البيانات. تبقى تفضيلات الموقع إلى أن تمحوها أو ينظفها المتصفح. تُحفظ الرسائل فقط للمعالجة أو المتابعة أو الالتزامات القانونية. يدير المزوّدون سجلاتهم ونسخهم الخاصة. تواصل لطلب الوصول إلى المعلومات المرسلة أو تصحيحها أو حذفها، مع مراعاة التزامات الاحتفاظ القانونية. لا يستطيع المطوّر الوصول عن بُعد إلى بيانات بقيت على الجهاز فقط.
